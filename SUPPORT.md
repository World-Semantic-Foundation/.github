## 🐛 Reporting Issues

### Semantic Errors

If you find an error in a concept definition or relationship:

1. Open an issue in `wsf-governance`
2. Reference the specific concept (use its semantic ID) or ADR
3. Describe the issue with evidence
4. Propose a fix or alternative interpretation

### Documentation Issues

For typos, broken links, unclear explanations:

1. Open an issue in the relevant repository
2. Reference the specific file and section

### Implementation Bugs

For software engine, connectors, or visualization issues:

1. Open an issue in the relevant implementation repository
2. Include reproduction steps
3. Include environment information

---

## 💬 Discussions

For architectural questions, design discussions, or use cases:

1. Open a discussion in `wsf-governance`
2. Reference relevant ADRs and concepts
3. Describe the use case or question clearly

---

## 🔒 Security

For security issues, **do not** open a public issue. Contact the maintainers directly through GitHub's security advisory feature on the relevant repository.

---

## 📜 Governance Questions

WSF follows a strict governance model. For questions about:

- **Why WSF exists**: Read [wsf-governance/README.md](https://github.com/World-Semantic-Foundation/wsf-governance)
- **How to propose changes**: Read [CONTRIBUTING.md](CONTRIBUTING.md)
- **Lifecycle and status**: Read the [Change Control Lifecycle](https://github.com/World-Semantic-Foundation/wsf-governance/blob/main/GOVERNANCE/CHANGE-CONTROL-LIFECYCLE.md) and [Semantic Status Model](https://github.com/World-Semantic-Foundation/wsf-governance/blob/main/GOVERNANCE/SEMANTIC-STATUS-MODEL.md)
